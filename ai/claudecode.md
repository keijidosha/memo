# Claude Code

## コマンド

|コマンド|説明|
|---|---|
| /effort | 思考の負荷さを設定 |
| /permission | パーミッション設定 |
| /memory | CLAUDE.md を編集 |
| /help | ヘルプ |
| /model | モデルを選択・変更 |
| /plan | プランニングモードに入る |
| /normal | 通常のモード/プランニングモードから抜ける |
| /chat | チャットモードに入る |
| /cost | トークン使用量と費用を表示 |
| /doctor | インストール状況を表示 |
| /init | CLAUDE.md を初期化 |
| /rewind | チェックポイントに戻る |
| /terminal-setup | Shift + Enter を設定 |
| ultrathink | このキーワードをプロンプトに含めることで、1回だけ深く考える |
